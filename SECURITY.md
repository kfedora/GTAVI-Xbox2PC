# Security & Takedown Policy

## Scope

**`kfedora/GTAVI-Xbox2PC`** hosts **zero executable code, zero compiled binaries, zero source code, and zero copyrighted game assets.** The entire repository consists of Markdown documentation, GitHub issue/PR templates, a harmless CI check, and a plain-text example `.toml` configuration.

Because no software is distributed here, remote code execution (RCE) vulnerabilities in our `README.md` are considered unlikely, though we applaud your creativity if you find one.

## Reporting a Vulnerability (or an Incoming Lawyer)

If you discover:
1. A broken Markdown table, dead anchor link, or syntax error in `gtavi-xbox2pc.example.toml`, OR
2. Any accidental user comment containing unauthorized external links or leaked hashes,

Please **open a GitHub Issue** or submit a **Pull Request** so it can be removed immediately.

## For Copyright Holders & Automated DMCA Scanners

Please review our [Legal Disclaimer](https://github.com/kfedora/GTAVI-Xbox2PC#legal-disclaimer) before submitting a notice under 17 U.S.C. § 512(c). There are no Rockstar Games, Take-Two Interactive, or Microsoft files stored anywhere in this repository's git history.
