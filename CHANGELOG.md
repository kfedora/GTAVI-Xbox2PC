# Changelog

All notable updates to the **`kfedora/GTAVI-Xbox2PC`** specification and documentation hub are documented in this file.

## [0.1.2-docs] - 2026-11-25

### Added
- `.github/workflows/verify-docs.yml` automated zero-IP & TOML sanity workflow.
- Structured GitHub Issue templates (`benchmark_report.yml`, `bug_report.yml`) and PR checklist.
- `SECURITY.md`, `CONTRIBUTING.md`, and standalone `gtavi-xbox2pc.example.toml` configuration file.
- Updated `PortWatchVI` milestone tracking for **Jason's *"Gone Fishing"* chapter**.

### Fixed
- Compacted ASCII frame-time flamegraph width so all 5 subsystems fit without horizontal scrolling.
- Renamed `-DWORKAROUND_MAGENTA_PALMS` to `-DFIX_MAGENTA_PALMS` across build docs and flag reference.

## [0.1.1-docs] - 2026-11-25

### Changed
- Rebranded documentation hub to **`kfedora/GTAVI-Xbox2PC`** (`Project VIctory / Leonida Heritage`).
- Added hardware benchmarks for RTX 5090 (4.9 FPS), RTX 5070 Ti (2.4 FPS), RX 9070 XT (3.6 FPS), and Intel Arc B770 (1.9 FPS).
- Added 416.6 ms CPU/GPU frame-time profiling breakdown and GDDR6 virtual memory bridge table.

## [0.1.0-docs] - 2026-11-24

### Added
- Initial public documentation release following the **November 24 DMCA takedown** of `Leonida` and 3,007 network repositories.
- Added explicit zero-IP legal disclaimer and AGPL-3.0 license file.
