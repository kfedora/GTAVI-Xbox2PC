# Contributing to GTAVI-Xbox2PC

Thank you for your interest in documenting the greatest **2.4 FPS** technical speedrun in PC gaming history!

## What We Accept

We gladly accept **documentation-only contributions** via Pull Requests or Issues:
* Updated `PortWatchVI` mission compatibility milestones
* Verified hardware benchmark entries (CPU, GPU, RAM, Backend, Avg FPS, 1% Low)
* Frame-time breakdown refinements and DXIL / Vulkan 1.4 architecture notes
* Typo fixes, formatting improvements, and new troubleshooting tips

## Strict Zero-IP Rules

To keep `kfedora/GTAVI-Xbox2PC` 100% compliant with GitHub Terms of Service and copyright law, **do NOT submit**:
1. Game assets, textures, `.rpf` archives, `.xex` / `.exe` binaries, shaders, or decryption keys.
2. Clean-room or leaked C++/Rust recompilation source code (per our docs-only repository policy).
3. Links to Discord servers, Telegram channels, torrent magnets, or file hosts distributing leaked builds.

Any Issues or PRs containing leaked files or piracy links will be closed and deleted immediately.
